# Souls-Like-Mobile
creating mobile game with housemates

## Nusantara world authoring

Open `Assets/NusantaraWorld/Scenes/NusantaraQuest_World.unity`. The former Region5Rework terrain and painted water now belong to this scene; its separate folder was removed. Recovery copies are under `Library/Nusantara/Region5ReworkSourceBackup` and `Library/Nusantara/CombinedWorldBackup`.

Every individual region contains 6 rows × 6 columns: 36 cells of 128×128 m, covering 768×768 m per region. Eight regions contain 288 cells in total. Each region uses one continuous ground plane. The World Foundation window can show each region’s cell grid in the Scene view; those lines are editor guides. Ground meshes, materials, tree and grass styles live under `Assets/NusantaraWorld/Models/Region1` through `Region8`; painted props live in the region’s `Details` folder. `Chunks` and `RegionChunks` terrain folders were removed. Original asset recovery copies are under `Library/Nusantara/RegionalGroundBackup`. Procedural geography, roads, rivers and decorations are disabled. Open **Tools → Nusantara → World Foundation** and choose **Show all regions** or **Edit Region 5 · Bujang Senang** (each region has its own button). Each **Edit Region** button shows only that region’s ground and saved props in the Scene view. **Show all regions** restores the combined world and loads all saved props across the map. Region visibility is editor-only; all grounds remain active for gameplay. **Tools → Nusantara → Edit Region 1–8** and **Show All Regions** are also direct shortcuts. Use the **Scene** tab to edit; the **Game** tab follows the player. Then use the Terrain, Water, Vegetation or AI No-Walk brushes to author it. **Tools → Nusantara → Preview → Brush Region 1–8** provides the same region previews. Apply prefab overrides or use **Save Region Chunk Changes** before changing preview areas, and save terrain and water using their brush tools.

To combine different region sizes, select `Assets/NusantaraWorld/NusantaraWorld.asset`, edit each region's **Chunk Grid Size**, then choose **Tools → Nusantara → Recombine Brush Region Grids**. A 6×6, 5×5 or 4×4 region can coexist in the same world. The command keeps Region 5 at its original world position and preserves retained chunk assets. Shrinking a region rejects removal of sculpted terrain, saved or staged vegetation, structures, gameplay, painted water, no-walk areas or the player's chunk. Mixed heights can leave empty space at the end of a shorter region's row; those spaces contain no chunk and are not streamed. Split water areas that cross regions before moving those regions apart.

Region size controls the authored map area. The regional ground stays available for collision with one near/far visual LOD; each 6×6 ground has 37,249 near vertices and 2,401 distant vertices. Mobile streaming separately requests props and gameplay within a nearby 3×3 area, a small border retention buffer and one concurrent Addressables load. Runtime AI navigation rebuilds only the area near the player. Shared materials are bundled once. Device profiling is still needed to establish a phone's frame rate and memory use; the current Editor build target is macOS.

Run **Tools → Nusantara → Run Brush World Checks** and **Run Terrain Brush Checks** to validate the layout, brushes and streaming budgets.


Chapter palettes: Region 1 Naga Seri Gumum (lake blue), 2 Harimau Penjaga Johor (fire orange/red), 3 Sang Kelembai (forest green), 4 Batu Belah Batu Bertangkup (stone grey), 5 Bujang Senang (river green/teal), 6 Raja Bersiong (blue/gold), 7 Ulek Mayang (sea teal), 8 Darkness (violet). The existing Region 5 ID and authored positions are preserved. Choose the chapter’s tree or grass in the separate Vegetation Painter **Brush style** dropdown; terrain colour painting remains in the Terrain Brush.

Regions 7 and 8 are disconnected floating islands 160 m below the mainland, with an open-air gap and a rock underside. At the centre of Region 1, approach the Ulek Mayang or Darkness gate and tap its travel button or press **E**, like the horse interaction. The island return gate takes you back to Region 1. Mounted travel carries the horse with its rider. `WorldRegionPortal.accessUnlocked` can be set by future Region 1 progression; it defaults to enabled for authoring and testing.
